# HOMESCAPE — Interactive 3D Living Building

An interactive Three.js building cutaway by **yngcompany**. Explore a multi-level home through real 3D rooms, animated characters, clickable spatial moments, and choreographed camera movement.

## Experience

- Navigate a 3D cutaway building with orbit controls
- Click characters and glowing in-world markers to focus the camera on each space
- Explore a rooftop, studio, game lounge, library, kitchen, and home office
- Real-time lighting, shadows, environment map, particle effects, and raycast interaction
- Responsive interface for desktop and mobile

## Stack

- React + Vite
- Three.js
- React Three Fiber + Drei

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
